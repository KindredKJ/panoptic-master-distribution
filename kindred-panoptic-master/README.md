# KINDRED PANOPTIC MASTER

A local-first geometric meta-control foundation for the Kindred Panoptic Box.

## What is materially different from the v1 K-Box bootstrap?

This implementation models the architecture itself as geometry:

- Port Zero at `(0,0,0)`
- six strategic cube faces
- three true opposite-face axis pairs
- twelve valid cube edges as moat intersections
- eight valid cube vertices as convergence positions
- X×Y×Z bounded operational volumes
- cross-strata fields and lattices
- containment / intersection / adjacency
- signed Ed25519 founder approvals
- hash-linked evidence
- fail-closed external adapters
- Panoptic master read model
- browser dashboard
- SQLite WAL state store

## Run

```powershell
.\Test-KindredPanopticMaster.ps1
.\Start-KindredPanopticMaster.ps1
```

Then open:

`http://127.0.0.1:8788/`

For the dashboard token, use the value of `KBOX_BOOTSTRAP_TOKEN` in `.env.local`.

## Reality boundary

This runtime creates and verifies the local architecture. It does not fabricate utility, telecom, banking, cloud, market, payment, government, or hardware integrations.
