# PANOPTIC COMMERCIAL SERVICE BLUEPRINT

## Operating principle
Panoptic Master stays founder-operated. Customers consume bounded services and verified outcomes.

## Service packaging
- Managed Panoptic service
- Per-site K-Box
- WATT module
- Communications/G3T module
- AI/agent module
- Companion/personal intelligence module
- Automation/workflow module
- Private/enterprise deployment
- API/developer access

## Revenue structures the software should support
- recurring subscription
- per-site license/service
- module subscription
- metered usage
- setup/integration fees
- support/managed-operations fees
- outcome/value-share contracts when explicitly agreed and lawful

## Accounting truth
Internal value is not collected revenue.
Track separately:
1. opportunity/quoted value
2. contracted value
3. invoiced amount
4. payment initiated
5. settlement confirmed
6. cash received
7. refunds/reversals
8. recognized revenue according to applicable accounting policy

No demo may mark value as cash.
