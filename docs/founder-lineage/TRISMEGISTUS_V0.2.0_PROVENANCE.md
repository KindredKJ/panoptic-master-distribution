## Architecture represented by the supplied repository

The implementation describes a single governed cognitive-compute runtime organized around a Unified Quad Runtime:

1. **Q1 — Context & Meaning:** semantic normalization, contextual resolution, semantic signatures, contradiction handling.
2. **Q2 — Memory & Learning:** episodic, semantic, procedural, causal, and counterexample memory; procedural confidence and consolidation boundaries.
3. **Q3 — Planning & Action:** conclusion formation, risk-sensitive tier selection, cognitive compilation, governed execution, fail-closed authorization.
4. **Q4 — Evidence & Resources:** execution receipts, provenance, resource accounting, artifact reuse, validity/invalidation conditions, and compute recirculation.

The runtime exposes a stable **World Contract** intended to allow the same runtime artifact to interact with validation environments or real systems without a separate simulation build or production fork.
